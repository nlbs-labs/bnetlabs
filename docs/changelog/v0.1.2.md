# v0.1.2 — 2026-05-16

**Phase 1 — stability & polish.**
`0.1.x` series. Still beta.

### Fixed

- Backend: Downgraded gin from v1.9.1 to v1.8.2 to eliminate broken `chenzhuoyu/base64x` transitive dependency
- Backend: Changed `owner_id`, `project_id`, `device_id` columns from `uuid` to `varchar(36)` — auth is stubbed with `"dev-user"` in Phase 1 (not a valid UUID)
- Backend: Added `json` tags to `Project` and `Device` Go structs — frontend now receives snake_case keys (`name`, `id`, `subnet_cidr`, etc.)
- Backend: Removed `not null;uniqueIndex` from Device `public_key` — now allows multiple devices per project without unique constraint violation
- Client: Fixed mixed named/unnamed return parameters in `generateKeyPair()` (Go 1.22 compat)
- Client: Fixed `:=` redeclaration error on `public` variable
- Frontend: Mobile-first responsive layout across all views (navbar, projects, devices, guide, report bug)
- Frontend: Code blocks in Guide now have copy-to-clipboard buttons
- Frontend: Added `host: '0.0.0.0'` to Vite config for external access
- Scripts: `start-dev.sh` and `stop-dev.sh` removed — migrated to PM2 (`ecosystem.config.js`)
- Scripts: Install script now falls back to `git clone + go build` when release binary is unavailable

### Changed

- All repository URLs updated from `github.com/bezn/bnetscale` to `git.nafi-labs.tech/Labs/bnetscale`

### Added

- `front/src/components/CodeBlock.vue` — reusable code snippet component with copy functionality
- `ecosystem.config.js` — PM2 config for managing backend (`go run main.go`) and frontend (`vite`) processes
- `releases/` — pre-built release binaries for direct download
- `.gitignore` entry for `.git-token.txt`
