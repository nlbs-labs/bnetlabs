# v0.1.1 — 2026-05-16

**Phase 1 — end-to-end P2P connectivity + install scripts.**
`0.1.x` series. Still beta.

Phase 1 finalization.

### Fixed

- Backend: WireGuard interface creation now properly configures gateway IP and listen port
- Backend: Hardcoded `"server-public-key"` and `"localhost:51820"` replaced with real per-project WG keys
- Backend: WireGuard interface created on project creation with generated server keypair
- Backend: WireGuard interface cleaned up on project deletion
- Backend: Device `AssignedIP` varchar size fixed (15→18) to accommodate CIDR notation
- Client: P2P peer list from handshake now saved to config and applied on `bnetscale up`
- Client: Private key piping to `wg set` fixed (StdinPipe)

### Added

- Install/update/uninstall scripts for Linux, macOS, and Windows
  - `scripts/install.sh` / `install.ps1` — download + install binary
  - `scripts/update.sh` / `update.ps1` — version-aware upgrade
  - `scripts/uninstall.sh` / `uninstall.ps1` — clean removal
- `scripts/build-release.sh` — cross-compile client for linux/amd64, linux/arm64, darwin/amd64, darwin/arm64, windows/amd64
- `Makefile` — convenience targets (client, release, clean)
- Backend: `PUBLIC_ENDPOINT` env var for WireGuard server endpoint configuration
- Backend: Project model stores per-project WG server keys (`wg_server_priv_key`, `wg_server_pub_key`)
- Documentation: Versioned changelog files at `docs/changelog/v0.1.0.md` and `docs/changelog/v0.1.1.md`
