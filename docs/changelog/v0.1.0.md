# v0.1.0 — 2026-05-16

**Phase 1 — Core P2P foundation.**
All Phase 1 releases are `0.1.x`. Beta until all phases done.

Initial Phase 1 release.

### Added

- Setup project structure (back, client, front, docs)
- Backend: Go + Gin + GORM + PostgreSQL foundation
- Backend: PostgreSQL migrations (projects, devices, join_tokens, ip_allocations)
- Backend: Custom cryptographic handshake server-side (5 langkah: HELLO, CHALLENGE, RESPONSE, CONFIRMATION, ACK)
- Backend: WireGuard orchestration (interface management per project, peer add/remove)
- Backend: IPAM (IP Address Management) — static allocation from 10.0.0.0/8 pool
- Backend: REST API — health, projects CRUD, devices CRUD, token generation, join endpoint
- Client: Curve25519 key generation, handshake client-side (HELLO → RESPONSE → ACK)
- Client: `bnetscale join <token>` — join project with one-time token
- Client: `bnetscale up` / `bnetscale down` — basic tunnel management (Linux)
- Client: `bnetscale status` — show connection status
- Client: Config stored at `/etc/bnetscale/{config.json,private.key}`
- Frontend: Vue 3 + Vite + Pinia + Vue Router + Tailwind CSS setup
- Frontend: Layout dasar (navbar, sidebar, struktur halaman)
- Frontend: Halaman Projects (list + create project)
- Frontend: Halaman Devices + Token generator UI per project
- Frontend: Halaman Login & Register
- Scripts: `start-dev.sh` dan `stop-dev.sh` untuk development workflow
- Documentation: AGENTS.md, CHANGELOG.md init
