# v0.1.3 — 2026-05-16

## Changes

### Server
- Set `PUBLIC_ENDPOINT=bnetscale.nlbs.me:51820` in PM2 ecosystem config (WireGuard endpoint now uses domain instead of localhost)
- Opened UFW port 51820/udp for WireGuard

### Client
- Improved error message when `bnetscale join` fails — now hints to use `--server https://bnetscale.nlbs.me`

### Installer
- Changed binary install path from `/usr/local/bin` to `/usr/bin` (always in `$PATH`, no `source ~/.bashrc` needed)
- Auto-installs `wireguard-tools` if missing
- Removed `source ~/.bashrc` requirement

### Documentation
- `--server` flag documented in help output
